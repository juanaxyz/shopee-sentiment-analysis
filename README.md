# Shopee Sentiment Analysis

Analisis sentimen review aplikasi Shopee dari Google Play Store menggunakan preprocessing
teks bahasa Indonesia, lexicon-based labeling, TF-IDF, FastText, SentenceTransformer,
dan beberapa model klasifikasi.

## Isi repository

- `playstore.ipynb` — notebook utama analisis.
- `images/` — visualisasi hasil analisis.

Dataset, hasil ekspor, dan model terlatih tidak disertakan dalam repository karena ukurannya
besar. Simpan file tersebut secara lokal sesuai struktur folder notebook:

- `playstore_reviews.csv`
- `exports/`
- `models/`
